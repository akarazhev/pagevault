Три шага до первого сохранения

Подключите локального помощника

PageVault сохраняет страницы в SQLite через программу на вашем компьютере. Установите её один раз для выбранного браузера.

  1. Откройте страницу загрузок.

    Открыть загрузки ↗
  2. Установите помощника для своего браузера.

    При обновлении закройте браузер и переподключите MCP-клиент. Существующая база и её путь сохраняются.

  3. Проверьте подключение.

    Откройте браузер после установки и нажмите кнопку ниже. Затем включите запись для нужного сайта через значок PageVault.
