Первый запуск

Подключите локального помощника

PageVault записывает данные в SQLite через локальную программу. Браузер запускает её автоматически и сохраняет соединение между запросами.

  1. Распакуйте полный комплект PageVault.

    В нём уже есть готовая программа для вашей ОС в папке bin. Для запуска дополнительные среды программирования не нужны.

  2. Зарегистрируйте помощника для своего браузера.

    Откройте терминал в папке проекта и выполните:

    macOS / Linux · Chrome
    bash install.sh chrome
    Windows · Chrome
    .\install-windows.cmd

    В Windows файл можно открыть двойным щелчком. Для другого браузера передайте edge, brave или chromium первым аргументом установщика. При обновлении сначала полностью завершите браузер. Подробности и выбор пути базы: README.md.

    ID этого расширения: —

  3. Проверьте подключение.

    Нажмите «Проверить» в разделе «Локальное хранилище». Затем откройте сайт и включите запись в меню PageVault.

Сохраняется доступное, уже загруженное содержимое. Медиафайлы, закрытые части страницы и ещё не загруженные записи не входят в архив автоматически.
